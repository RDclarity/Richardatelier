Hosting di questo sito

Questo sito è ospitato staticamente tramite GitHub Pages (GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, USA; parte di Microsoft Corporation). All'apertura di una pagina, GitHub, in qualità di responsabile del trattamento, elabora automaticamente dati di accesso tecnici (tra cui indirizzo IP, data/ora, pagina richiesta) per fornire il sito. La base giuridica è il nostro legittimo interesse a una fornitura stabile e sicura del sito (art. 6, par. 1, lett. f GDPR). Ulteriori informazioni: GitHub Privacy Statement.

Statistiche di visita anonime

Indipendentemente dal tuo consenso ai cookie, conteggiamo le visualizzazioni di pagina in modo anonimo tramite il nostro backend (Supabase, sede server Francoforte/UE). Vengono rilevati esclusivamente il percorso visitato, il referrer, l'impostazione della lingua e un ID di sessione generato casualmente, presente solo nella memoria di sessione del browser e cancellato alla chiusura della scheda. Non vengono memorizzati né l'indirizzo IP né altri identificatori personali, e non viene eseguito alcun fingerprinting — questo conteggio non è quindi riconducibile a una persona ai sensi della normativa sulla privacy e funziona indipendentemente dal banner dei cookie (art. 6, par. 1, lett. f GDPR, legittimo interesse a una misurazione aggregata e non personale).

Consenso ai cookie, strumenti di analisi e marketing

Alla prima visita mostriamo un banner cookie con una vera scelta di opt-in. Finché non presti espresso consenso, non viene caricato alcuno script di analisi o marketing (Google Consent Mode v2, consenso predefinito "negato"). Solo dopo aver cliccato su "Accetta" attiviamo, se configurati:

  • Google Analytics 4 (Google Ireland Limited, Gordon House, Barrow Street, Dublino 4, Irlanda) — finalità: statistiche di utilizzo anonime.
  • Google Ads Conversion Tracking (Google Ireland Limited) — finalità: misurazione dell'efficacia degli annunci pubblicitari.
  • Meta Pixel e Conversions API (Meta Platforms Ireland Limited, 4 Grand Canal Square, Dublino 2, Irlanda) — finalità: misurazione dell'efficacia e creazione di segmenti di pubblico per gli annunci sulle piattaforme Meta (Facebook/Instagram). La Conversions API trasmette inoltre alcuni dati sugli eventi lato server.

Ciò può comportare un trasferimento di dati verso gli USA; i fornitori indicati si basano a tal fine sulle clausole contrattuali standard dell'UE. La base giuridica è il tuo consenso (art. 6, par. 1, lett. a GDPR). Puoi revocare il tuo consenso in qualsiasi momento con effetto per il futuro cancellando i relativi cookie dal tuo browser — il banner riapparirà alla tua prossima visita e potrai scegliere nuovamente.

Moduli di contatto, richiesta e candidatura

Quando compili uno dei moduli su questo sito (ad es. richiesta di contatto, scheda progetto, candidatura, richiesta fornitori), trattiamo i dati da te inseriti (tra cui nome, indirizzo e-mail, numero di telefono, testo del messaggio ed eventuali file caricati come foto, planimetria o curriculum) esclusivamente per l'elaborazione della tua richiesta. L'invio avviene tramite una funzione server (Supabase Edge Functions, sede server Francoforte/UE) che ci recapita i dati via e-mail; per le richieste di contatto viene inoltre memorizzato un record nel nostro sistema interno, per poter seguire l'andamento della tua richiesta. La base giuridica è l'esecuzione di misure precontrattuali adottate su tua richiesta (art. 6, par. 1, lett. b GDPR). Conserviamo questi dati per il tempo necessario a elaborare la tua richiesta, oppure per il periodo previsto da eventuali obblighi di conservazione di legge (ad es. in caso di conclusione di un contratto).
